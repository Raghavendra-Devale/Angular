# Data Handling

This chapter explains how Angular applications communicate with backend APIs and manage data coming from external services.

Angular provides the **HttpClient module** to perform HTTP requests such as fetching data, creating resources, updating records, and deleting items.

## Why Data Handling Matters

Most real-world Angular applications interact with backend systems.

Angular provides tools that help:

* communicate with APIs
* process asynchronous responses
* manage errors
* modify requests globally

These capabilities allow Angular applications to integrate cleanly with backend services.
