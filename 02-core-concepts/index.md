# Angular Core Concepts

This chapter covers the fundamental building blocks used to create Angular user interfaces.

These concepts control how Angular:

* renders UI
* binds data
* updates the DOM
* creates reusable UI behavior

Understanding these topics is essential before building real applications.

## Why These Concepts Matter

Angular applications are built using components and templates.

Templates display data, while Angular features like data binding, directives, and pipes allow the UI to become dynamic.

These concepts make Angular applications interactive and reactive.
