# Reactive Programming (RxJS)

This chapter covers the fundamentals of reactive programming in Angular using RxJS.

Angular heavily relies on RxJS for handling asynchronous data such as:

* HTTP requests
* user events
* real-time updates

## Why This Matters

Angular applications are asynchronous by nature.

Instead of handling data step-by-step, Angular uses **streams of data**.

RxJS provides tools to:

* create data streams
* transform data
* handle async operations
* manage state

Understanding RxJS is essential for working with:

* HttpClient
* routing events
* reactive forms
