# Angular Routing

This chapter explains how Angular applications navigate between views without reloading the page.

Angular uses a client-side router to map URL paths to components. When the URL changes, Angular loads the corresponding component into the view.

## Why Routing Matters

Single Page Applications (SPA) require navigation without full page refresh.

Angular Router provides:

* URL based navigation
* dynamic component loading
* protected routes
* modular application loading

These capabilities allow Angular applications to behave like traditional multi-page websites while maintaining the performance advantages of SPAs.
